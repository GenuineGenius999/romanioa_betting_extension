# 🚀 Quick Installation Guide

## Step-by-Step Installation

### 1. Download the Extension
- Download or clone this repository to your computer
- Extract the files if downloaded as a ZIP

### 2. Open Chrome Extensions Page
- Open Google Chrome
- Type `chrome://extensions/` in the address bar
- Press Enter

### 3. Enable Developer Mode
- Look for the "Developer mode" toggle in the top-right corner
- Click to enable it (toggle should be blue)

### 4. Load the Extension
- Click the "Load unpacked" button
- Navigate to the folder containing the extension files
- Select the folder and click "Select Folder"

### 5. Verify Installation
- The extension should appear in your extensions list
- Look for "Superbet Tennis Extension" with a tennis ball icon
- The extension should show as "Enabled"

### 6. Pin the Extension (Optional)
- Click the puzzle piece icon in Chrome's toolbar
- Find "Superbet Tennis Extension" in the list
- Click the pin icon to keep it visible

## 🧪 Testing the Installation

### Quick Test
1. Click the extension icon in your toolbar
2. You should see a popup with "🎾 Tennis Live" header
3. The popup should show extension status and settings

### Full Test
1. Open the `test.html` file in Chrome
2. Click "Check Extension Status"
3. You should see "✅ Extension is working!"

### Real Environment Test
1. Visit https://superbet.ro/pariuri-sportive/tenis/live
2. Look for the "🎾 Tennis Live" button in the top-right corner
3. Click it to open the tennis panel

## 🔧 Troubleshooting

### Extension Not Appearing
- Make sure Developer mode is enabled
- Try refreshing the extensions page
- Check that all files are in the correct folder

### Extension Not Working
- Check the browser console for errors (F12 → Console)
- Try reloading the extension
- Verify you're on a Superbet.ro page

### Button Not Visible
- Ensure you're on the tennis live page
- Check if the page has loaded completely
- Try refreshing the page

## 📞 Need Help?

If you're having issues:
1. Check the troubleshooting section above
2. Open `test.html` to test the extension
3. Check the browser console for error messages
4. Make sure all files are present in the extension folder
